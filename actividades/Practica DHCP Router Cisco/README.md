# Practica DHCP Router Cisco

Actividad AulaStep para configurar DHCP en un router Cisco con Packet Tracer dentro del módulo [[0227 - Servicios en red]].

## Ruta de la actividad

- [[pasos/00-preparacion]]: topología, datos y entrega.
- `actividad.yml`: configuración global.
- [[pasos/01-interfaz-primera-lan]]: puerta de enlace de la primera LAN.
- [[pasos/02-primer-pool]]: pool DHCP y clientes automáticos.
- [[pasos/03-exclusiones]]: rangos reservados y concesiones.
- [[pasos/04-segunda-lan]]: interfaz y pool para una segunda red.
- [[pasos/05-entrega]]: evidencias y comprobación final.

## Enfoque didáctico

La secuencia separa la creación de la red, el servicio DHCP, las exclusiones y la validación. Cada paso pide una comprobación observable para evitar que la configuración se limite a copiar comandos.
