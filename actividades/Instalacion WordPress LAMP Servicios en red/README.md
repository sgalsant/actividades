# Instalación WordPress LAMP Servicios en red

Actividad AulaStep para desplegar manualmente WordPress sobre Ubuntu Server 24.04 LTS con VirtualHost propio, HTTPS obligatorio, base de datos limitada, protección adicional de `/wp-admin`, logs independientes y entrega documentada.

## Ruta de la actividad

- [[pasos/00-presentacion]]: escenario, requisitos y planificación.
- [[pasos/01-preparacion-entorno]]: descarga, extracción y permisos.
- [[pasos/02-base-datos]]: base de datos y usuario limitado.
- [[pasos/03-virtualhost-https]]: VirtualHost, TLS, redirección y logs.
- [[pasos/04-proteccion-wp-admin]]: autenticación HTTP adicional.
- [[pasos/05-instalacion-web]]: instalador web y `wp-config.php`.
- [[pasos/06-personalizacion]]: tema, entrada y ajustes generales.
- [[pasos/07-verificacion-logs]]: verificaciones y registros.
- [[pasos/08-documentacion-entrega]]: PDF y evidencias.
- [[pasos/09-reflexion]]: reflexión y exportación `.aulawork`.
